# Security policy

Please report a vulnerability privately, never in a public issue, pull request or discussion.

Use GitHub's private vulnerability reporting: open the repository's **Security** tab and choose **Report a vulnerability**.
The report is visible only to the maintainers until it is fixed and published.

Please include what is affected (version or commit, the request or page involved), how to reproduce it and what an attacker
could gain. You will get an answer in that report; please give us a reasonable time to fix the issue before you disclose it.

Only the latest version on the default branch receives security fixes.
