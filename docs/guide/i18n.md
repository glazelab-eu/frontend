# i18n

Base rules (`$t` for everything visible, stable keys, identical keys in all dictionaries, no translated user content): `AGENTS.md` "Code rules".

- `lib/i18n/locales.ts` is the one list of languages. A new language adds: its loader to `messages.ts` and `src/test/dictionaries.ts`; its own name to `LanguageSelect`; a tag word per label to `models/vision/labels.source.json` and `labels.json` (copied by hand, no model run).
- Only `en.json` is bundled (fallback; `MessageKey` is typed from it). Other languages are lazy chunks imported only in `messages.ts`; nothing else imports a dictionary statically except tests (`src/test/dictionaries.ts`, e2e `support/locales.ts`).
- `lib/i18n/loader.ts`: a switch happens only after the dictionary arrived, in one step (no frame mixes two languages); only the last of overlapping choices applies; `glazelab:locale` is stored only once shown; a failed fetch is forgotten so the next choice retries.
- `setLocale` answers a promise of whether it switched; `loadLocale` loads without switching (for tests using `translate(…, { locale })`).
- A failed load keeps the shown language: `LanguageSelect` puts its value back, `App.svelte` shows `language.loadFailed` (`onLocaleFailure` → `app.showError`).
- `main.ts` mounts only after `startLocale()`. A start never hangs: after `START_LIMIT_MS` (4 s) the app starts in English and switches when the dictionary arrives (the saved preference is kept).
- Dictionary chunks are precached by the default glob: never add them to `globIgnores` (offline starts need them).
- Server-message keys and the photo-suggestion tags need no dictionary of their own.
- `TermsView` shows `terms.translationNote` in every language but English (only the English terms bind; a translation is no version bump).
- A nulled author shows the translated deleted-account label.
- Italian and Spanish are unreviewed machine translations; use `docs/i18n-glossary.md` for every new text.
- A translation keeps the English ICU arguments, plural and select ones included (`i18n.test.ts` over `src/test/icu.ts`, the parser svelte-i18n uses).
- Pass an accessible name's key in the attribute (`aria-label={$t('…')}`, `title`, `alt`, `label`, `…Label`): `accessible-names.test.ts` sees only those, not a name kept in a variable or picked from a map.
- Placeholders are short examples that fit a 320 px phone: shorten the text, not the font.
- A new tight screen or a longer text joins `e2e/specs/overflow.spec.ts` (phone screens in Italian and Spanish; the tightest ones in all languages at 320 and 390 px). Other specs: `language.spec.ts`, the service-worker block of `offline.spec.ts`.
